# 🧠 DSA AI Mentor

> **Learn DSA. Understand the logic. Improve your problem-solving skills.**

**DSA AI Mentor** is an interactive web-based learning project designed to help beginners practice **Data Structures and Algorithms** in a simple and engaging way.

The goal is to make DSA practice less intimidating by providing an easy-to-use interface where learners can explore concepts, work with problems, and gradually improve their problem-solving approach.

---

## ✨ Features

* 📚 **DSA Learning** — Explore important Data Structures and Algorithms concepts.
* 💡 **Beginner-Friendly Interface** — Simple UI designed for students who are starting with DSA.
* 🧩 **Problem-Solving Practice** — Practice DSA-based questions and understand their logic.
* ⚡ **Interactive Experience** — Learn and interact with the application through a web interface.
* 🎯 **Focused Learning** — Designed around improving logical thinking and coding problem-solving skills.
* 📈 **Expandable Architecture** — The project can be extended with more problems, topics, hints, and learning features.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Jahnavee612/DSA-AI-Mentor.git
```

### 2️⃣ Navigate to the Project

```bash
cd DSA-AI-Mentor
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run the Project

Run the project using the setup defined in `package.json`.

If the project does not require a local server, you can also open:

```text
index.html
```

directly in your browser.
